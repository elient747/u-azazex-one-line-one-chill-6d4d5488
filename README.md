One original line, 1 to 200 characters: a single sentence of horror — a baby monitor whispering, in a dead grandmother's voice, a Wi-Fi password changed yesterday.

## Run it

```sh
python3 -P -s main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
